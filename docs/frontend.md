# Web-интерфейс T12/T18

## Скоуп

T12 реализует один desktop-only экран актуального транспорта на карте Санкт-Петербурга:

- карта MapLibre с позициями из `GET /api/v1/vehicles`;
- фильтр по маршруту;
- карточка выбранного транспортного средства;
- состояние API, ручное и автоматическое обновление;
- loading, empty и error states.

T18 добавляет desktop-раздел «Аналитика»: карту и таблицу узких участков, сравнение ETA,
аномалии и характеристики кластеров маршрутов. Фильтры используют человекочитаемые названия
маршрутов из текущего GTFS. Периоды и версии расчётов UI получает из `analytics_current`, который
batch-задачи переключают только после успешной записи serving-таблиц.

## UI-принципы

- интерфейс на русском языке;
- целевой сценарий — desktop, мобильная адаптация намеренно не выполняется;
- повторяющиеся представление данных, API-вызовы и состояния выносятся в shared-компоненты и
  функции, копипаст не допускается;
- используются официальные компоненты и паттерны Material UI из
  [`llms.txt`](https://mui.com/material-ui/llms.txt), кастомные элементы управления не создаются;
- экран остаётся информационным и компактным: без декоративных подзаголовков, промо-текста,
  градиентов и карточек, не поддерживающих пользовательский сценарий;
- тяжёлая карта отделена от панели управления; цвета и отступы берутся из MUI theme tokens.

## Запуск

Вместе с API и Cassandra:

```bash
docker compose up -d web
```

Эта команда поднимает только web, API и Cassandra. Чтобы на карте появились точки, нужен живой
поток позиций: collector, Kafka и `spark-position-stream` должны работать прямо сейчас, потому что
API отдаёт только позиции не старше `API_VEHICLE_FRESHNESS_SECONDS`. Названия маршрутов в фильтре
появляются после batch-джоба `spark-static-serving`; без него фильтр показывает `route_id`, а карта
работает.

Интерфейс доступен по адресу `http://localhost:${WEB_EXTERNAL_PORT}`. Nginx проксирует `/api`,
`/ready` и `/health` в FastAPI, поэтому отдельная CORS-настройка для контейнерного запуска не
нужна.

Локальная разработка:

```bash
npm ci --prefix apps/web
npm run dev --prefix apps/web
```

Vite проксирует API на `http://localhost:${API_EXTERNAL_PORT:-8000}`.

Если локальный TLS proxy подменяет сертификаты npm registry, предпочтительно добавить его CA в
Node.js. Временный локальный workaround:

```bash
NPM_CONFIG_STRICT_SSL=false npm ci --prefix apps/web
NPM_CONFIG_STRICT_SSL=false docker compose build web
```

Отключённую проверку сертификатов нельзя сохранять в общей конфигурации.
